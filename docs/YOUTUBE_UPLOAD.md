## Title

DoorSignal — From doorbell to done. | Ring + AWS Hackathon Demo

## Description

DoorSignal turns Ring door events into accountable guest, delivery, and service workflows for small workplaces.

In this 2:45 demo:

- a guest checks in from their own phone and sees the host response;
- a delivery moves from received to collected;
- a scheduled service visit is distinguished from an unmatched after-hours arrival;
- durable AWS processing keeps acceptance, retries, and failures visible;
- bounded scene context never performs facial recognition or authorizes actions.

Try DoorSignal: https://doorsignal.site

Source code: https://github.com/AmirmLotfy/doorsignal

Built for the Ring primary track and AWS Builder and Open Source mini challenges in the Build, Ship, Shape: Amazon Developer Hackathon 2026.
