# DoorSignal brand assets

The master icon was generated with OpenAI's internal image-generation model for this project on September 10, 2026, then inspected and exported locally. It is an original doorway/threshold symbol with a restrained signal dot, warm off-white surface, charcoal structure, and muted green accent.

Working generation direction:

> Create a single original logo icon for DoorSignal: a simple doorway or threshold mark with one signal dot. Warm off-white, charcoal, and restrained muted green. Flat vector-like geometry, subtle human-made irregularity, no gradients, no glossy 3D, no text, no mockup, no existing brand resemblance, centered with generous negative space and a transparent background.

`doorsignal-icon-master.png` is the preserved source output. `exports/` contains PNG sizes for browser, Apple touch, and PWA use. These logo files are released with the repository under Apache-2.0.

Devpost and YouTube composites will have separate prompts and provenance records because they must include a verified product screenshot and licensed source imagery.
